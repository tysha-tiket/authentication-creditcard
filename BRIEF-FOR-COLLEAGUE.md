# Brief to paste into Claude

**How to use it:**

1. Unzip `prototype-starter-kit.zip`, e.g. into `Documents`.
2. Open the Claude desktop app → **Code**, and choose the unzipped `prototype-starter-kit`
   folder as the project folder.
3. Paste the message below.

---

Hi Claude! I've got a "prototype starter kit" from a colleague, and it's the folder you're in
now. I want to set up the same thing they have:

- a homepage that lists my design prototypes,
- the Tiket Design System gallery,
- an example prototype I can copy,
- all of it online on Vercel (free), behind **one shared password**, with the fun password page
  (the mascot follows my typing and puts on sunglasses when I show the password).

Please:

1. **Read `SETUP.md` first** (and `CLAUDE.md`). It has every step, the rules, and
   troubleshooting. Follow it in order.
2. **Do as much as you can yourself:** install, build, personalise, run it locally and show me,
   create and link the Vercel project, publish, and verify the live site.
3. **Ask me** what name to show on the homepage, and what Vercel project name and
   `*.vercel.app` address I want. Suggest something if I'm not sure.
4. **Leave two things to me:** logging in to Vercel (`npx vercel login`) and choosing the
   password (`set-password.sh`). Start the command in a terminal and tell me when to type. Never
   ask me to tell you the password.
5. **Explain each step in simple words**, since I'm not very technical. Show me the links when
   it's done:
   - the local preview links,
   - the live link,
   - how to change the password,
   - how to add a new prototype later.

If something fails, tell me what happened and fix it before moving on.
